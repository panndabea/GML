# GML

**Gyro Motion Language (GML)** — a framework that translates continuous gyroscope data (tilt, rotation, movement patterns) into meaningful shared digital experiences at scale.

## Components

See [GML_COMPONENTS.md](./GML_COMPONENTS.md) for the full structured proposal of eight motion primitives:

| Component | Motion | Meaning |
|-----------|--------|---------|
| **GROUNDSWELL** | Sustained forward pitch tilt | Momentum, conviction, forward pressure |
| **TREMOR** | Rapid lateral micro-oscillation | Tension, stakes, risk awareness |
| **ORBIT** | Slow circular yaw rotation | Alignment, synthesis, convergence |
| **ANCHOR** | Complete sustained stillness | Stability, resolve, groundedness |
| **SURGE** | Sharp rapid upward pitch snap | Excitement, enthusiasm, energy |
| **PULSE** | Rhythmic forward-back pitch oscillation | Agreement, affirmation, active support |
| **PIVOT** | Abrupt 90° yaw rotation | Reframing, course correction, change of mind |
| **CASCADE** | Progressively deepening forward tilt | Escalation, urgency, building pressure |
