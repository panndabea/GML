# GML

**Gyro Motion Language (GML)** — a framework that translates continuous gyroscope data (tilt, rotation, movement patterns) into meaningful shared digital experiences at scale.

## Components

See [GML_COMPONENTS.md](./GML_COMPONENTS.md) for the full structured proposal of three motion primitives:

| Component | Motion | Meaning |
|-----------|--------|---------|
| **GROUNDSWELL** | Sustained forward pitch tilt | Momentum, conviction, forward pressure |
| **TREMOR** | Rapid lateral micro-oscillation | Tension, stakes, risk awareness |
| **ORBIT** | Slow circular yaw rotation | Alignment, synthesis, convergence |
